# medium_blog

실생활 문제를 **파이썬 · 데이터 엔지니어링 · AI/ML · 알고리즘**으로 해결하기 위한 학습/실험 저장소입니다.

## 프로젝트 목표
- 실생활에서 파이썬과 자료구조/알고리즘 개념이 어떻게 적용되는지 실습 중심으로 정리합니다.
- AI에 다가가기 위해 필요한 기초 지식부터 적용 사례까지 단계적으로 학습합니다.
- 데이터 수집 → 가공 → 분석 → 시각화 → 인식(Recognition)까지 전체 흐름을 연결해봅니다.

## 핵심 주제
- 시각장애 보조를 위한 인식 기술 아이디어
- 음성 인식 (Speech Recognition)
- 사물 인식 (Object Recognition)
- 공통 키워드: **Recognition**

## 디렉터리 가이드
- `Python/`: 파이썬 문법, 라이브러리, 실전 노트북
- `data engineering/`: 데이터 파이프라인, Spark, 로그
- `Artificial Intelligence and Machine Learning/`: 머신러닝/딥러닝 학습 노트
- `data structure & algorithm/`: 자료구조/알고리즘 개념 및 실습
- `recognition/`: 인식 관련 실습
- `database/`: 데이터베이스 학습 정리

## 본격 개발 로드맵
1. **기초 정리 표준화**
   - 노트북 상단에 목표/입력/출력/결론 템플릿을 통일
   - 파일명 규칙과 태그 체계 정립
2. **재현 가능한 실습 환경 구성**
   - 공통 의존성 파일(`requirements.txt` 또는 `environment.yml`) 정리
   - 데이터 샘플 경로 규칙 통일
3. **미니 프로젝트 고도화**
   - 데이터 수집 + 전처리 + 모델링 + 결과 리포트까지 한 사이클 완성
   - recognition 주제(음성/사물)별 베이스라인 모델 기록
4. **문서화 및 자동화**
   - 각 프로젝트 README에 실행 방법 추가
   - 체크리스트 기반 자체 점검(재현성/가독성/확장성)

## 작업 원칙
- 작은 단위로 자주 실험하고 결과를 문서로 남깁니다.
- "왜 이 방법을 선택했는가"를 코드/노트에 반드시 기록합니다.
- 완성보다 **지속 가능한 개선**을 우선합니다.
