# medium_blog

이 저장소는 **"배운 지식을 연결해 실제 문제를 푸는 사람"**이 되기 위한 학습 아카이브이자 실행 기반 플레이북입니다.

## North Star (위대한 방향성)

> "모든 데이터를 다 가지는 것"보다 중요한 것은,
> **핵심 데이터를 찾고 → 검증하고 → 사고하고 → 반복 실행하는 체계**를 갖추는 것입니다.

나는 이 저장소를 다음 목표로 확장합니다.

1. **지식 수집**: 파이썬, 데이터 엔지니어링, 자료구조/알고리즘, AI/ML 학습 자산을 지속 축적
2. **지혜화**: 단순 요약이 아니라 "왜"와 "언제"를 설명할 수 있는 판단 기준 정리
3. **실행 자동화**: 작은 실험을 빠르게 만들고 검증하는 루틴 구축
4. **영향력 확장**: 결과물을 문서/노트북/프로젝트로 재사용 가능하게 구조화

## Greatness System v1

아래 5단계를 반복하면, 지식이 실력으로 변환됩니다.

### 1) Capture — 입력(지식 흡수)
- 하루 1개 이상: 개념/논문/문서/코드 스니펫 수집
- 분류 기준: `Python`, `data structure & algorithm`, `data engineering`, `AI/ML`

### 2) Distill — 정제(핵심 추출)
- 각 학습 항목마다 3문장 작성
  - 무엇인가?
  - 왜 중요한가?
  - 어디에 쓰는가?

### 3) Connect — 연결(융합 사고)
- 매주 1회: 서로 다른 분야 2개를 연결한 미니 노트 작성
  - 예: `Spark 파이프라인` + `A/B Testing`
  - 예: `Python collections` + `탐색 알고리즘`

### 4) Build — 제작(실행)
- 2주 1회: 작더라도 끝나는 결과물 1개 배포
  - 노트북, 대시보드, 데이터 파이프라인 문서, 실험 리포트

### 5) Review — 회고(개선)
- 월 1회: 잘한 점 3개 / 개선점 3개 / 다음 달 집중 주제 1개 기록

## 30일 확장 계획

- **Week 1:** Python 핵심 문법 + 자료구조 기초 복습
- **Week 2:** 알고리즘 문제 해결 + 실험 코드 정리
- **Week 3:** 데이터 파이프라인 소형 프로젝트 1개 완성
- **Week 4:** AI/ML 노트북 1개 개선 + 결과 요약 문서화

## 운영 원칙 (중요)

- "세계의 모든 데이터"를 한 번에 다루려 하지 말고,
  **문제 중심으로 필요한 데이터부터 접근**합니다.
- 사실/주장/해석을 분리해서 기록합니다.
- 재현 가능성(다시 실행 가능한 코드/노트북)을 항상 우선합니다.
- 배운 것을 반드시 출력(문서화/공유)해 내 것으로 만듭니다.

- AI 개념 이해와 확장
- 시각장애/음성인식/사물인식 등 `recognition` 관련 탐구
