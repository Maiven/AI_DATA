# Product Growth Studio (MVP)

사용자 경험(UX), 온보딩, 전환율(CVR)을 한 화면에서 설계/점검할 수 있는 실전형 미니 제품입니다.

## 왜 만들었나
- 학습 노트 중심 저장소를 **실행 가능한 제품 실험 공간**으로 전환
- 아이디어 → 진단 → 실행 우선순위까지 빠르게 연결

## 핵심 기능
1. **제품 상태 입력**: 유입, 활성화, 결제 단계별 수치 입력
2. **퍼널 분석**: 단계별 이탈률/전환율 계산
3. **온보딩 진단**: 가치 제시, 첫 성공 경험(TTV), 마찰 요인 체크
4. **실행 우선순위 자동화**: ICE(Impact/Confidence/Ease) 점수 기반 정렬
5. **주간 실험 백로그 생성**: 바로 실행 가능한 실험안 템플릿 제공

## 실행 방법
```bash
pip install streamlit pandas
streamlit run product_growth_studio/app.py
```

## 권장 사용 흐름
1. 현재 퍼널 수치를 입력해 병목 단계를 찾습니다.
2. 온보딩 체크리스트에서 낮은 점수 항목을 고릅니다.
3. 개선 아이디어를 3개 이상 입력하고 ICE 점수화합니다.
4. 상위 1~2개를 1주 스프린트 실험으로 실행합니다.
5. 다음 주에 동일 화면에서 전환 개선폭을 재측정합니다.
